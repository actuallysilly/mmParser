# HOW TO ADD YOUR MMS

DO THIS FOR BOTH OF YOUR MODELS
1) copy paste the discord message into the large text area
2) in the mass1...mass3 tabs, select the mass youre adding
3) click parse -> the mass is added
4) do this for all 3 of your masses
5) click save
6) repeat for the 2nd model

# HOW TO SELECT WHICH MASS YOURE USING

Just click 1 2 3 in the massNo area, do it for both models
