Installing MMA, and giving it permission to type

Ten minutes, most of it waiting. macOS will try to stop you twice — both times are expected, and this page tells you exactly which button to press.

Read this part, even if you skip the rest. MMA types into other apps for you. macOS treats that as a serious privilege, so it will not let the app work until you tick two boxes in System Settings by hand. Nothing can do this for you — not the installer, not us.

If you skip those boxes, MMA opens perfectly, looks completely fine, and does nothing when you press a key. That is the single most common way this goes wrong.

  1. Copy the app to Applications

    Open the MMA.dmg file you were sent. A window appears with the MMA icon and a shortcut to your Applications folder. Drag the icon onto the folder.

    Then eject the disk image — the white drive icon on your desktop or in the Finder sidebar. Run MMA from Applications, not from the disk image.

  2. Open it, and get refused

    Double-click MMA in Applications. macOS will refuse to open it:

    What you'll see

    “MMA” can't be opened because Apple cannot check it for malicious software.

    This software needs to be updated. Contact the developer for more information.

    Move to Bin OK
    This is expected

    It does not mean the app is unsafe. It means nobody paid Apple's yearly developer fee to have it rubber-stamped. Press OK — not “Move to Bin”.

    Now go to Apple menu → System Settings → Privacy & Security, scroll to the bottom, and you'll find a line saying MMA was blocked. Click Open Anyway, then confirm with Touch ID or your password.

    You only ever do this once.

  3. Let it watch the keyboard

    MMA has to notice when you press its keys, even while you're working in another app. macOS calls that Input Monitoring, and it will ask the first time you run it.

    What you'll see

    “MMA” would like to receive keystrokes from any application.

    Grant access to this application in Privacy & Security settings, located in System Settings.

    Deny Open System Settings

    Click Open System Settings and switch MMA on in the list. If you clicked Deny, or no dialog appeared, go there yourself: Privacy & Security → Input Monitoring, then use the + button to add MMA from Applications.

  4. Let it type

    Watching the keyboard and typing are two separate permissions on macOS, so you have to grant both. This one is called Accessibility.

    Go to Privacy & Security → Accessibility and switch MMA on. Same list layout, same + button if it isn't there.

    Easy to miss

    Some Macs only prompt for one of the two. Check both lists by hand. If MMA can see your keys but nothing gets typed, this is the one that's off.

  5. Quit MMA completely, then open it again

    This step is not optional, and it is the one people skip.

    macOS only hands those permissions to an app when it starts. The copy of MMA that's running right now was launched before you granted anything, so it still has nothing. It will keep doing nothing until you restart it.

    Press ⌘ Q, or right-click the icon in the Dock and choose Quit. Then open it again from Applications.

  6. Check it works before you rely on it

    Open TextEdit, make a new empty document, and click into it so the cursor is blinking in the page.

    Press ⌃ 1. Your first follow-up should type itself into the document.

    If it does, you're finished — MMA sits in the menu bar and works in any app. If it doesn't, the table below covers every way this fails.

If it isn't working

What you seeWhat it meansFix
Nothing at all happens Almost always a permission that was granted but never picked up Quit MMA fully (⌘Q) and reopen it. If that fails, check both Input Monitoring and Accessibility are actually switched on
It worked yesterday, not today The app was replaced or updated, so macOS revoked its permissions Switch MMA off and back on in both lists, then quit and reopen
Text appears in the wrong place The cursor wasn't in the message box Click directly into the box first. Having the window in front is not enough
Text pastes but never sends The app it's typing into wants a different key to send Tell whoever set this up — it's a settings change, not a permissions problem
Can't find MMA in the permission list It's only listed once it has asked, or been added by hand Use the + button and pick MMA from Applications

Two things worth knowing

  • Updates reset the permissions. Every time you replace MMA with a newer copy, macOS treats it as a different app and quietly withdraws both permissions. Toggling each one off and on again is the fastest fix.
  • MMA can type into anything that's focused. That's how it works, and it's why the permissions are strict. Keep the right window in front before pressing a key.

MMA — the follow-up sender. This guide covers macOS 13 Ventura and later.

On macOS 12 and earlier, step 2 is different: right-click the app, choose Open, then Open again in the dialog.
